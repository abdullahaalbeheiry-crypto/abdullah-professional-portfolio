# Procurement & Supply Chain Toolkit

A practical foundation for sourcing, supplier evaluation, purchase control, and inventory visibility.

## Included
- RFQ comparison template
- Supplier evaluation scorecard
- Purchase requisition checklist
- Inventory movement template
- Procurement KPI guide

## Suggested sourcing workflow
Need identification → specification → approved requisition → RFQ → evaluation → approval → purchase order → receipt and inspection → invoice matching → supplier review.
